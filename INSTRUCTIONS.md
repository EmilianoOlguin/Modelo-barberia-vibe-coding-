# 🚀 Cómo ejecutar este proyecto localmente

Este proyecto fue desarrollado con **React**, **Vite** y **Tailwind CSS**. Sigue estos pasos para ponerlo en marcha en tu computadora.

## 📋 Requisitos Previos

Asegúrate de tener instalado [Node.js](https://nodejs.org/) (versión 18 o superior recomendada).

## 🛠️ Pasos para la instalación

1. **Clonar el repositorio:**
   Si tienes Git instalado, ejecuta:
   ```bash
   git clone https://github.com/EmilianoOlguin/Modelo-barberia-vibe-coding-.git
   ```
   *O simplemente descarga el archivo ZIP desde el botón "Code" en GitHub y descomprímelo.*

2. **Abrir en VS Code:**
   Abre la carpeta del proyecto con Visual Studio Code.

3. **Instalar dependencias:**
   Abre una terminal integrada en VS Code (Ctrl + ñ) y escribe:
   ```bash
   npm install
   ```
   *Esto descargará todas las librerías necesarias para que el proyecto funcione.*

4. **Iniciar el servidor de desarrollo:**
   Una vez terminada la instalación, ejecuta:
   ```bash
   npm run dev
   ```

5. **Ver el proyecto:**
   En la terminal verás un enlace similar a `http://localhost:5173`. Haz clic en él o cópialo en tu navegador para ver la página funcionando.

---
**Nota:** Si el proyecto utiliza variables de entorno (como APIs de Google Sheets), asegúrate de configurar tu archivo `.env` siguiendo las instrucciones del desarrollador principal.
